# PDF تەرجىمانى (PDF Translator to Uyghur)

بۇ قورال ھەر قانداق تىلدىكى PDF ھۆججەتلىرىنى ئۇيغۇر تىلىغا ئاپتوماتىك تەرجىمە قىلىپ بېرىدىغان كۈچلۈك Agent. 

## 🌟 ئالاھىدىلىكى ۋە ئىقتىدارلىرى (Features)

* **ئۇنىۋېرسال تەرجىمە:** ھەر قانداق تىلدىكى PDF نى ئۇيغۇر تىلىغا توغرا ۋە راۋان تەرجىمە قىلىدۇ.
* **بەتلەرنى پارچىلاش:** ئەسلى ھۆججەتتىكى ھەر بىر بەتنى ئايرىم-ئايرىم كېسىپ ئېلىپ، ئۇلارنى مەخسۇس بىر ئايرىم ھۆججەت قىسقۇچقا رەتلىك ساقلايدۇ.
* **Obsidian قوللىشى (Markdown):** تەرجىمە قىلىنغان مەزمۇنلارنى Obsidian قاتارلىق يۇمشاق دېتاللاردا ئوقۇشقا ۋە تەھرىرلەشكە قۇلايلىق بولۇشى ئۈچۈن بىۋاسىتە `.md` فورماتىدا ساقلايدۇ.
* **PDF قىلىپ چىقىرىش:** ئاخىرىدا تەييار بولغان بارلىق `.md` ھۆججەتلەرنى ئاپتوماتىك بىرلەشتۈرۈپ، تولۇق بىر ئۇيغۇرچە PDF ھۆججىتى قىلىپ چىقىرىپ بېرىدۇ.

# PDF Translator (to Uyghur)

A powerful agent designed to automatically translate PDF documents from any language into Uyghur.

## 🌟 Key Features

* **Universal Translation:** Translates PDF files from any language into the Uyghur language.
* **Page-by-Page Extraction:** Crops and extracts each original page individually, saving them organized in a separate dedicated folder.
* **Obsidian-Friendly (Markdown):** Saves the translated content in Markdown (`.md`) format, making it incredibly convenient to read and edit in Obsidian.
* **Final PDF Export:** Automatically compiles all the generated `.md` files and exports them as a single, complete Uyghur PDF document at the end of the process.
