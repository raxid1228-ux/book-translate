# تەييار ماتېرىياللار

- `template.html`: RTL/UKIJ Tuz ئىشلىتىدىغان، بېتى ئايرىلغان HTML چىقىرىش قېلىپى.
- `uyghur-rtl.css`: Obsidian دا `uyghur-rtl` CSS سىنىپىغا ئىشلىتىلىدىغان snippet.
- `fonts/README.md`: UKIJ Tuz فونتىنى ئىجازەتلىك ئورنىتىش ئۇچۇرى.
- `logo.png`: ماھارەتنىڭ كۆرۈنۈش بەلگىسى.
- `template.docx`: Word دا ئىشلىتىش ئۈچۈن RTL پاراگراف ئۇسلۇبى بار قېلىپ.

فونت ھۆججىتى تەمىنلەنمىگەن؛ ئۇنى قايتا تارقىتىش ھوقۇقى يوق دەپ قارىلىدۇ. HTML/Word قېلىپى چىقىرىش ياردەمچى ماتېرىيالى بولۇپ، ئاساسىي pipeline بەت PDF ۋە Obsidian Markdown ھاسىل قىلىدۇ.
