# ياخشى ۋە ناچار ئۈلگىلەر

## ياخشى: بەت بويىچە ئايرىش

```text
original_pages/page-0001/page-0001.pdf
translation_drafts/page-0001.md
```

ھەر تەرجىمە بېتى ئۆزىنىڭ قىسقۇچىدا ساقلىنىدۇ:

```text
translated_pages/page-0001/page-0001.md
```

ھەر بەتنىڭ مەنبە PDF سى ۋە ئۇيغۇرچە تەرجىمىسىنى بىر-بىرىگە باغلاپ تەكشۈرگىلى بولىدۇ.

## ناچار: بىر ھۆججەتكە يىغىش

```text
translated_pages/all-pages.md
```

بۇنداقتا بەتلەرنىڭ چېگراسى، قايتا تەكشۈرۈش ۋە مەنبە بەت بىلەن سېلىشتۇرۇش قىيىنلىشىدۇ.

## ياخشى: گۇمانلىق OCR نى ئاشكارىلاش

```markdown
بۇ ماددىدا پەقەت [ئوقۇش ئېنىق ئەمەس: «12» ياكى «17» بولۇشى مۇمكىن] دېگەن سان كۆرۈندى.
```

ساننى مەزمۇنغا قاراپ تاللىۋېتىش ئەمەس، ئېنىقسىزلىقنى ساقلاش ئىشەنچلىك تەرجىمە قىلىشنىڭ بىر قىسمى.

## ناچار: مەنىنى يوشۇرۇن تولۇقلاش

```markdown
ئەسلىدىكى مۇجمەل جۈملىنى تەرجىمان ئۆزىچە چۈشەندۈرۈپ، ئېنىق بىر ھۆكۈمگە ئايلاندۇردى.
```

## ياخشى: Markdown ۋە ئىزاھ قۇرۇلمىسىنى ساقلاش

```markdown
## 2-باب

ئاساسىي چۈشەنچە ۋە ئۇنىڭ شەرتلىرى.

- بىرىنچى شەرت
- ئىككىنچى شەرت
```
