# ئاتالغۇ لۇغىتى

تۆۋەندىكىسى بۇ ماھارەتنىڭ كۆرسەتمىسىدە ئىشلىتىلىدىغان مۇقىم ئاتالغۇلار. تەرجىمە قىلىنىۋاتقان PDF ساھەسىنىڭ ئۆزىگە خاس لۇغىتىنى بۇ تىزىملىككە ئاپتوماتىك ئالماشتۇرماڭ؛ ئىشلەتكۈچى تەمىنلىگەن ساھە لۇغىتى ئالدىنقى ئورۇندا تۇرىدۇ.

| English | ئۇيغۇرچە | ئىزاھ |
|---|---|---|
| PDF | PDF ھۆججىتى | قىسقارتىلمىنى ئۆز پېتى ساقلاڭ |
| Markdown | Markdown | ھۆججەت فورماتىنىڭ نامى |
| page | بەت | بەت نومۇرىدا `1-بەت` شەكلى |
| source language | مەنبە تىلى | ئەسلى ھۆججەتنىڭ تىلى |
| target language | نىشان تىل | بۇ ماھارەتتە ئۇيغۇرچە |
| OCR | OCR / رەسىمدىن تېكىست تونۇش | لازىم بولغاندا قىسقا چۈشەندۈرۈڭ |
