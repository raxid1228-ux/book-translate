# تەرجىمان

PDF نىڭ ھەر بىر بېتىنى ئەسلى ھۆججەت قىلىپ ساقلاپ، مەزمۇنىنى ئەدەبىي ۋە مەنىگە سادىق ئۇيغۇرچىغا تەرجىمە قىلىپ، بەت نومۇرى بىلەن ئايرىم Obsidian Markdown ھۆججىتى قىلىپ چىقىرىدۇ.

## ئىش تەرتىپى

1. ئىشلەتكۈچى تەمىنلىگەن PDF ۋە چىقىرىش ئورنىنى جەزملەشتۈرۈڭ. چىقىرىش ئورنى بېرىلمىسە، PDF يېنىدا `<نام>-تەرجىمە/` ئىشلىتىڭ. ئەسلى PDF نى ھەرگىز ئۆزگەرتمەڭ ياكى ئۆچۈرمەڭ.
2. Node.js 20+ ۋە بەلگىلەنگەن npm بوغچىلىرى بارلىقىنى تەكشۈرۈڭ؛ ئورنىتىلمىغان بولسا [API قوللانمىسى](./references/api-guide.md) دىكى بۇيرۇقنى ئىشلىتىڭ.
3. PDF نى `node scripts/convert.js extract "<pdf>" "<چىقىرىش>"` بىلەن بەتلەرگە پارچىلاڭ. چىقىرىلغان تېكىستنى بەت بويىچە ئوقۇڭ؛ تەرتىپ، بەت نومۇرى ۋە مەزمۇن تولۇقلىقىنى تەكشۈرۈڭ.
4. ھەر بىر بەتنى ئايرىم تەرجىمە قىلىپ، `translation_drafts/page-0001.md` شەكلىدە ساقلاڭ. رەقەم PDF دىكى ئەسلى بەت رەقىمىگە ماس بولسۇن. ئەسلى بەتتىكى جەدۋەل، تىزىملىك، ماۋزۇ، ئىزاھ ۋە پايدىلانمىلارنى ساقلاڭ. چىقىرىلغان تېكىستنى ياردەمچى مەنبە قىلىپ ئىشلىتىڭ؛ كۆپ ستون، جەدۋەل، ئالاھىدە بەلگە ۋە گۇمانلىق ئوقۇشلۇقتا بەت PDF نى كۆرۈپ ئەسلى بىلەن سېلىشتۇرۇڭ.
5. تېكىستى يوق ياكى يېتەرلىك بولمىغان بەتلەرنى ئەسلى بەت PDF نى كۆرۈپ OCR/كۆرۈنۈش ئارقىلىق ئوقۇڭ. ئىشەنچسىز سۆز، كېسىلگەن بەت ياكى ئوقۇلمايدىغان مەزمۇننى پەرەز قىلماڭ؛ مۇناسىۋەتلىك بەت نومۇرىنى كۆرسىتىپ ئىشلەتكۈچىدىن ئېنىقلاش سوراڭ ياكى نامەلۇم قىسمىنى بەلگە قىلىڭ.
6. تەرجىمىنى [ئۇسلۇب قوللانمىسى](./references/style-guide.md) ۋە [ئاتالغۇ لۇغىتى](./references/glossary.md) بويىچە تەكشۈرۈپ، تەرجىمە لايىھەلىرىدىن Markdown چىقىرىڭ:
   `node scripts/convert.js markdown "<چىقىرىش>" --title "<ھۆججەت نامى>" --source-language "<مەنبە تىلى>"`
7. `python scripts/validate.py "<چىقىرىش>"` بىلەن بەتلەر، Markdown، RTL مېتا سانلىق مەلۇماتى ۋە فونت ئۇسلۇبىنى تەكشۈرۈڭ. مەغلۇپ بولسا خاتالىقنى ئوڭشاپ قايتا ئىجرا قىلىڭ.
8. ئىشلەتكۈچىگە چىقىرىش يولىنى، تەرجىمە قىلىنغان/يېرىم قالغان بەت سانىنى، OCR ياكى ئېنىقلاشقا موھتاج بەتلەرنى ۋە Obsidian دا UKIJ Tuz نى ئىشلىتىش ئۈچۈن فونتنى سىستېمىغا ئورنىتىپ CSS snippet نى قوزغىتىش كېرەكلىكىنى ئېيتىڭ.
9. ئەڭ ئاخىرىدا تەييار بولغان بارلىق md ھۆججەتلەرنى يىغىپ بىر pdf قىلىپ تەييارلاڭ.
## نەتىجە قۇرۇلمىسى

```text
<چىقىرىش>/
├── original_pages/page-0001/page-0001.pdf
├── original_pages/page-0001/source.txt
├── translation_drafts/page-0001.md
├── translated_pages/page-0001/page-0001.md
└── _assets/uyghur-rtl.css
```

ھەر بىر بەتنىڭ `page-0001` نامى PDF دىكى تەرتىپىگە ماس. ھۆججەتلەرنى بەتلەر ئارىسىغا قوشۇپ قويماڭ. چىقىرىش ۋە تەرجىمە قائىدىلىرى ئۈچۈن [مىساللار](./references/examples.md) ۋە [API قوللانمىسى](./references/api-guide.md) نى ئوقۇڭ.
